Redefinir acesso

Como não há servidor, não é possível recuperar a senha por e-mail. Para impedir acesso indevido aos dados locais, não é possível redefinir o login sem autenticação. Guarde sua senha e mantenha backups seguros.

Os dados são salvos neste navegador, por perfil. Outro computador só pode receber dados com uma exportação e importação autorizadas. O login local não criptografa o banco.

A importação substitui apenas o perfil atual, mediante confirmação. O backup legado em JSON continua disponível abaixo.

Backup completo

O e-mail e a senha do acesso local ficam em armazenamento separado e não são incluídos no backup. Esta tela não representa um sistema de autenticação online. Use Salvar para gravar os dados no navegador, Baixar backup para gerar um arquivo completo e Importar backup para restaurar em outro computador.

O armazenamento principal é o IndexedDB. As configurações de personalização e os anexos também fazem parte do backup.
